## 1. 目的與範圍 (Purpose & Scope)
本專案為一套專門用於台股市場的自動化投資決策提示詞產生器（`committee_prompt_generator.html`）。其核心宗旨在於將複雜的「量化動能篩選」與「嚴格風控模型」封裝進入三位一體的 AI 代理人（Agent）聯合會審流程。透過標準化的提示詞結構，引導大語言模型（LLM）依序扮演不同角色，剔除人性情緒干擾，產出具備高度工程化標準的股市診斷與部位計算報告。

### 適用範圍
* **主要標的（MAIN）**: 支援台股個股與各類型 ETF（市值型、高股息型、主動型、累積型）。
* **比較組（COMPARE）**: 支援多檔對手標的進行橫向相對強弱（RS）動能極限排序。
* **變現與被動收入應用**: 可完美結合 NotebookLM 知識包打包銷售或轉化為 YouTube 自動化技術影音矩陣。

## 2. 三階段代理人架構 (Three-Stage Agent Architecture)

系統透過流程閉環設計，嚴格依序由以下三位虛擬專家共同決策：

```
[① 數據研究員] ──彙整消息與動態──> [② 基本面分析師] ──計算RS動能濾網──> [③ 風控與決策官] ──精確部位與止損──> 最終決策報告
```

1. **① 數據研究員 (Data Researcher)**
   * **職責**: 負責搜集並彙整最新網路消息面、產業動態及加權指數整體趨勢（如力守45,000點大關等大盤脈絡）。
   * **規範**: 無權威來源的精確數字必須嚴格標註為【無資料】，確保數據基石之純淨度。
2. **② 基本面分析師 (Fundamental Analyst)**
   * **職責**: 評估標的之內在估值（如不配息累積型 ETF 的複利摩擦成本優勢）與執行「相對強弱（RS）」動能篩選。
3. **③ 風控與決策官 (Risk & Decision Officer)**
   * **職責**: 依據總資金與單筆最大風險上限，啟動量化風控模組，計算可容許虧損、每股承受風險、精確購買股數（部位規模）與技術止損點。

## 3. 核心量化指標與風控公式 (Core Metrics & Formula)

### 3.1 RS 回看機制 (RS Lookback Period)
* **邏輯**: 自決策當天（T）往回推算指定的交易日天數（如 `25日`），強制將所有對比組標的拉回同一時間基準線，計算該區間的累積報酬率：
  $$\text{RS區間累積報酬率} = \frac{\text{最新收盤價} - \text{回看起始收盤價}}{\text{回看起始收盤價}} \times 100\%$$

### 3.2 RS 通過門檻 (RS Passed Threshold)
* **邏輯**: 系統將所有標的的 RS 報酬率進行降序排列。主要標的必須明確擊敗 **$\ge N$ 檔**（如 `至少通過：2檔`）對手，方能通過「動能合格濾網」。若不達標，系統將直接觸發拒絕買入機制。

### 3.3 凱利風控部位規模計算 (Position Sizing)
風控官依據 **Albert 風格嚴格安全限額** 進行三步公式解構：
1. **可容許最大虧損金額 (Total Risk Capital)**:
   $$\text{Risk TWD} = \text{總資金} \times \text{單筆最大風險\%} \quad (\text{範例: } 200,000 \times 2\% = 4,000\text{ 元})$$
2. **每股承受風險空間 (Per-Share Risk)**:
   $$\text{Per-Share Risk} = \text{現價 (Entry Price)} - \text{技術止損價 (Stop Loss Price)}$$
3. **可購入精確股數 (Max Shares)**:
   $$\text{Shares} = \lfloor \frac{\text{Risk TWD}}{\text{Per-Share Risk}} \rfloor$$
*系統會進行雙重覆核，確保當股價跌破止損價時，整體本金虧損精確鎖定在 2% 上限。*

## 4. 系統參數配置範例 (System Parameter Configurations)

以下為 v3.0.0 委員會實戰運行的標準量化參數：

| 參數名稱 | 配置數值 | 備註說明 |
| :--- | :--- | :--- |
| **總資金 (Capital)** | `\$200,000 TWD` | 本次決策可動用之最高總曝險母數。 |
| **單筆最大風險 (Max Risk)** | `2%` | 當技術止損觸發時，最大僅允許虧損 \$4,000 元。 |
| **RS 回看天數 (Lookback)** | `25日` | 用於評估近期短中期強弱動能的時間賽道。 |
| **RS 至少通過 (Passed)** | `2檔` | 主要標的至少需擊敗比較組中 2 檔(含)以上的對手。 |
| **目標報酬 (Target)** | `25%` | 用於設定獲利了結與長線資本利得的預期目標價。 |

* **對戰組合設定**:
  * **MAIN**: `009816.TW` (凱基台灣TOP50 - 不配息累積型)
  * **COMPARE**: `0050.TW`、`006208.TW`、`00407A.TW`(主動式)、`00919.TW`、`00878.TW`

## 5. 檔案結構與安裝指南 (Installation & File Structure)

```
├── committee_prompt_generator.html   # 本地端提示詞產生器核心（內建 i18n / 多主題切換）
└── README.md                         # 本份技術架構與操作說明手冊
```

### 使用步驟
1. 雙擊打開 `committee_prompt_generator.html`（此工具為純前端開發，完全無須架設伺服器，具備高攜帶性與隱私性）。
2. 在介面上輸入您要診斷的「主要標的」與「比較組」代號。
3. 調整風控與 RS 參數（可使用內建的快捷 Chip 按鈕快速導入）。
4. 點擊 **"Generate Prompt"**，系統將會依據 Albert Style 生成完美的繁體中文三階段 Agent 聯合審查提示詞。
5. 將提示詞複製並餵給 LLM (如 Gemini 1.5 Pro / Claude 3.5 Sonnet) 執行，即可獲得深度診斷報告。
